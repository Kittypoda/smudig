# Smudig

**Abonnementsbaserte nettsider for små bedrifter**

## Om prosjektet

Smudig er en abonnementsbasert nettsidetjeneste utviklet gjennom enkeltpersonforetaket SMLT ROLSTAD.

Konseptet er rettet mot små bedrifter som ønsker profesjonelle nettsider med en forutsigbar månedlig kostnad, uten å måtte håndtere teknisk oppsett, drift og vedlikehold selv.

## Teknisk løsning

Smudig utvikles med React og Sanity CMS.

Løsningen bygger på gjenbrukbare komponenter og ulike nettsidemaler som kan tilpasses forskjellige bedrifter med relativt få kodeendringer.

Sanity benyttes som innholdsstyringssystem (CMS), slik at innholdet på nettsidene kan administreres og oppdateres uten større endringer i kildekoden.

Målet er å effektivisere utviklingsprosessen og gjøre det mulig å levere individuelt tilpassede nettsider med utgangspunkt i en felles teknisk løsning.

## Tjenesten

Smudig skal tilby:

- Design og utvikling av nettsider
- Valg og tilpasning av nettsidemaler
- Responsivt design
- Innholdsstyring gjennom Sanity CMS
- Publisering og teknisk oppsett
- Løpende drift, vedlikehold og oppdateringer

## Prosjektstatus

Smudig er under utvikling.

Den tekniske løsningen er påbegynt, med fokus på å etablere en fleksibel struktur som gjør det mulig å gjenbruke komponenter og tilpasse nettsider til ulike kunder.

## Videre utvikling

Planlagte arbeidsoppgaver inkluderer:

- Videreutvikling av React-komponenter og nettsidemaler
- Videreutvikling av integrasjonen med Sanity CMS
- Utforming og testing av ulike designmaler
- Optimalisering av responsivt design og brukeropplevelse
- Utvikling av demonstrasjonsprosjekter og portefølje
- Utarbeidelse av abonnementsmodeller og tjenestepakker
- Markedsføring og klargjøring for lansering
